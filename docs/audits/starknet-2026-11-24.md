# Starknet support evidence — 2026-11-24

Spectra catalogs Starknet mainnet (`starknet`) with Ready (formerly Argent X)
accounts: receive, STRK and ETH balances, STRK and ETH transfers from a
deployed account and from one the send deploys first, phrase and raw-key
import, and watch-only import. Every reading below was taken on 2026-11-24.

## Accounts

| Fact | Value | Source |
|---|---|---|
| Wallet secret | The phrase's Ethereum key at `m/44'/60'/0'/0/0`, as ethers' `HDNodeWallet.fromPhrase` reads it | argent-x `WalletCryptoSharedService.restoreSeedPhrase` |
| Second seed | That key through `num.toHex` and `sanitizeBytes(…, 2)`: its leading zero bytes dropped | argent-x `ArgentSigner` constructor |

| Account class | `0x036078334509b514626504edc9fb252328d1a240e4e948bef8d0c08dff45927f` (Argent account 0.4.0) | @argent/x-shared 1.79.4 (2026-08-19), `TXV3_ACCOUNT_CLASS_HASH` and the latest of `ARGENT_ACCOUNT_CONTRACT_CLASS_HASHES`; argent-contracts-starknet `deployments/account.txt` |

was released 2025-08-14 with the note "not yet supported by Ready clients or

mainnet blocks read through PublicNode (to block 18,465,962), the one
`DEPLOY_ACCOUNT` deployed class
`0x4a444ef8caf8fa0db05da60bf0ad9bae264c73fa7e32c61d245406f5523174b`, not an
Argent class; among the `INVOKE` v3 senders of those blocks, the first five
Argent accounts found were all 0.4.0.
